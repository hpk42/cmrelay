cmrelay documentation
*******************************************

.. image:: ../../vendor/www/collage-top.png :target: https://chatmail.at

How to set up and maintain a `chatmail <https://chatmail.at>`_ relay
with ``cmrelay``, a single-file installer that turns
a fresh Linux machine into a working relay.

cmrelay is experimental and lives beside the established cmdeploy-based
`chatmail relay <https://github.com/chatmail/relay>`_,
whose documentation at https://chatmail.at/docs also
covers everything that is the same on a cmrelay host:
the ``chatmail.ini`` settings, running behind a reverse proxy,
reverse DNS, and how a chatmail relay works.

Contributions and feedback are welcome
at https://github.com/chatmail/cmrelay.
