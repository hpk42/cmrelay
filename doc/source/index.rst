*******************************************
cmrelay documentation
*******************************************

.. image:: ../../vendor/www/collage-top.png
   :target: https://chatmail.at

This documentation details how to setup, maintain and understand
`chatmail <https://chatmail.at>`_ relays installed with ``cmrelay``,
a single-file installer that turns a fresh Linux machine
into a working chatmail relay.

cmrelay is experimental and lives beside the established
cmdeploy-based `chatmail relay <https://github.com/chatmail/relay>`_,
whose documentation is at https://chatmail.at/docs.

Contributions and feedback welcome through the
https://github.com/chatmail/cmrelay repository.
